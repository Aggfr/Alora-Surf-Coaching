# Alora Design System

The live reference for the **Coach** and **Surfer** platforms of Alora Surf Coaching. Every component on this site is the real React code from [`design-system/`](https://github.com/Aggfr/Alora-Surf-Coaching/tree/main/design-system), styled only with its tokens. The site rebuilds and republishes on every change merged to `main`.

## How to use this site

- **Theme:** switch between **Dark** (default) and **Light** with the paintbrush button in the toolbar. Every example and every token value follows it.
- **Controls:** open a component and change its props in the Controls panel to see each variant and state.
- **Docs:** each component page shows its examples first, then the full guidelines from its `.docs.md` file: purpose, when to use it, anatomy, tokens, accessibility and anti-patterns.
- **Accessibility:** the Accessibility panel runs axe checks on the story you are viewing.
